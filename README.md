## Installation

```shell
git clone https://github.com/jeremy-code/isomorphic-compress.git
cd isomorphic-compress
pnpm install
```

## Usage

```shell
# Lint and format code with Oxlint and Oxfmt
pnpm lint
pnpm format

# Build
pnpm build
```
